# Permission Audit PDF Report Generator

This folder converts the JSON generated by `audit_permissions.py` into a professional PDF report for audit evidence, business review, security review, and governance documentation.

## Folder structure

```text
permission_audit_pdf_report/
  config_report.py
  generate_permission_audit_pdf.py
  requirements.txt
  README.md
  input_json/
    audit_permissions_sample.json
  output_pdf/
```

## 1. Install dependencies

```bash
pip install -r requirements.txt
```

## 2. Put your JSON file in `input_json/`

Example:

```text
input_json/audit_permissions_20260614_233537.json
```

## 3. Configure the JSON path

Open `config_report.py` and change:

```python
INPUT_JSON = BASE_DIR / "input_json" / "audit_permissions_sample.json"
```

Example:

```python
INPUT_JSON = BASE_DIR / "input_json" / "audit_permissions_20260614_233537.json"
```

## 4. Generate the PDF using config

```bash
python generate_permission_audit_pdf.py
```

The PDF will be created inside:

```text
output_pdf/
```

## 5. Generate the PDF using command-line parameters

```bash
python generate_permission_audit_pdf.py --input input_json/audit_permissions_20260614_233537.json
```

Optional custom output:

```bash
python generate_permission_audit_pdf.py --input input_json/audit_permissions_20260614_233537.json --output output_pdf/my_audit_report.pdf
```

## Recommended audit evidence package

Keep both files together:

```text
audit_permissions_YYYYMMDD_HHMMSS.json
permission_audit_report_YYYYMMDD_HHMMSS.pdf
```

The JSON is the machine-readable evidence. The PDF is the human-readable business report.
